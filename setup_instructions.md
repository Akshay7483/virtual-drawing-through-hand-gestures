# Setup Instructions

## Prerequisites
- Python 3.11 installed
- Webcam

---

## Installation

1. Install required libraries:

py -3.11 -m pip install -r requirements.txt

---

## Run the Application

1. Go to backend folder:

cd src/backend

2. Start the Flask server:

py -3.11 app.py

3. Open your browser and go to:

http://127.0.0.1:5000

4. Click "Try Now" to start drawing.

---

## Important Note
Make sure Python 3.11 is used. MediaPipe may not work properly with newer Python versions.
