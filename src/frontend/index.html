Draw with your Hands in Mid-Air

An interactive Python application using OpenCV and MediaPipe to translate your hand gestures into virtual art.

Download & Run View on GitHub

Features

Real-time Processing

Instant tracking and drawing using your webcam.

Advanced Hand Tracking

Powered by MediaPipe for precise finger and joint detection.

Multiple Tools

Switch colors and clear the canvas using natural gestures.

How it Works

This application captures your webcam feed and processes each frame using OpenCV. It then applies Google's MediaPipe hand tracking model to detect 21 3D landmarks on your hand.

Based on the relative positions of your fingers, the app detects specific gestures. For example, if only your index finger is up, it switches to "drawing mode". If both index and middle fingers are up, it switches to "selection mode" to choose colors or clear the screen.

How to Run Locally

Terminal 
git clone https://github.com/Akshay7483/virtual-drawing-through-hand-gestures.git
cd virtual-drawing-through-hand-gestures
pip install -r requirements.txt
cd src/backend
python draw_hand_gestures.py
